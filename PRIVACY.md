# Privacy Policy — My Telegram Media Downloader

**Last updated:** 2026-08-11

This extension does not collect, store, transmit, or sell any user data.

## What the extension does

When you click its download button inside Telegram Web's media viewer, the
extension reads the currently-displayed image or video — content already
loaded into the page by Telegram for you to view — and saves it to your
computer using your browser's normal download mechanism.

## What it does not do

- It does not send any data to a server operated by the developer, or to
  any third party other than Telegram itself (to fetch the media you're
  already viewing, using the same requests Telegram's own player makes).
- It does not use analytics, telemetry, or tracking of any kind.
- It does not store data beyond the brief, in-memory processing needed to
  complete a download you initiated.
- It does not access any part of Telegram Web other than the media
  currently open in the viewer.

## Permissions

The extension requests host permissions for `web.telegram.org` and
`webk.telegram.org` only. These are used solely to inject the download
button into Telegram Web's own interface and to fetch the media file
you're already viewing — nothing else.
